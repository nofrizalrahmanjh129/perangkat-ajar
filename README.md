# Perangkat Ajar KIK TJKT

Aplikasi perangkat ajar (ATP, CP-TP, Prota, Promes, KKTP, jurnal, modul ajar, bahan ajar, administrasi wali kelas, analisis penilaian, daftar hadir, daftar nilai, rubrik, dan ulangan) untuk mata pelajaran Kreativitas, Inovasi dan Kewirausahaan (KIK), kelas XI dan XII TJKT.

## Cara membuka
1. Buka link situs di Chrome atau Edge.
2. Pilih kelas di bagian atas menu kiri.
3. Isi Identitas & Pengaturan terlebih dahulu (nama sekolah, guru, NIP, kepala sekolah).
4. Isi Data Siswa di menu 16. Data Nilai.

## Catatan penting
- Data setiap guru tersimpan di browser masing-masing. Data tidak ikut terbagi dengan guru lain.
- Untuk memindahkan data ke perangkat lain, gunakan Ekspor data (.json) di menu Identitas, lalu Impor di perangkat tujuan.
- Isi awal CP, TP, dan modul adalah draf. Periksa kembali sesuai Capaian Pembelajaran yang berlaku sebelum digunakan.
- Aplikasi bisa dipakai offline setelah halaman pertama dibuka.
